TOVEN FOODS · WEB V10 FOTORREALISTA + OPTIMIZADA
===============================================

1. Abre esta carpeta en Visual Studio Code.
2. Abre index.html con Live Server (extensión de VS Code).
3. También puedes hacer doble clic en index.html para abrir la web localmente.
4. Para compartir el sitio con otras personas hay que publicarlo con un hosting.

FOTOGRAFÍAS
- assets/hero/portfolio.webp, process.webp, sorting.webp y quality.webp: escenas PROMOCIONALES GENERADAS DIGITALMENTE, no fotografías documentales de la planta.
- assets/empresa/trabajo-real.webp: recorte de una fotografía real compartida por la empresa en esta conversación.
- assets/productos/: recortes fotográficos fotográficas. Cambiar por fotos reales cuando estén disponibles.
- El símbolo del encabezado proviene del logotipo oficial proporcionado.

RENDIMIENTO
- El material gráfico se pasó de PNG a WebP, con resolución y calidad optimizadas.
- Las fotos de secciones inferiores usan lazy loading.
- El carrusel se detiene al salir de la pantalla, cambiar de pestaña, pasar el mouse, usar teclado o pedir movimiento reducido.
- La web usa fuentes del sistema, sin descargas extra de fuentes.
- El menú, filtro, búsqueda y orden siguen funcionando sin librerías adicionales.

DATOS POR COMPLETAR ANTES DE PUBLICAR
- Número real de WhatsApp, correo, domicilio y textos empresariales aprobados.
- Fotografías reales y permiso de las personas retratadas, si corresponde.
- Certificaciones y controles solo cuando se confirme su existencia.
- El formulario de contacto es una maqueta, no envía mensajes.
- La pasta de ajo está en desarrollo y no se anuncia como producto comercial disponible.
